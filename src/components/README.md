# Componentes compartidos

- `ui`: botones, campos y modales reutilizables.
- `layout`: encabezado, navegación y pie de página.
- `auth`: acceso con Google y onboarding.
- `events`: tarjetas, filtros y formularios de eventos.
- `organizations`: componentes de agrupaciones.

Estas carpetas contienen interfaz. Las operaciones de servidor van en `src/server`.
